# Codex Model Advisor Router 0.9.0

在 Codex Desktop 中按任务选择模型与推理强度，继续使用原来的输入框。

- Jev 自动选择、只建议和固定规则三种模式。
- 本地设置页、Windows 加密密钥存储和主动连接检查。
- 可选项目摘要：同项目对话共享，多个文件夹共用，可预览、修改和关闭。
- 精简、可缩放的小窗，支持展开、托盘唤起和尺寸记忆。
- 完整状态页区分选型建议、请求配置、服务端完成配置和最终消息。
- 工具续跑复用本轮选择；Jev 放弃或失败时保留原配置。
- Windows x64 ZIP 自带运行时，支持安装、更新、停用、卸载和回退。
- 中文安装管理窗口集中提供安装、设置、重启和更新；无需从命令行启动。

安装从固定规则开始。配置自己的 OpenCode Zen 密钥并同意发送任务信息后，在设置页开启自动选择。下载后请核对 `SHA256SUMS.txt`。

[安装与恢复](INSTALL.md) · [隐私说明](../PRIVACY.md)

## English

Choose models and reasoning effort for tasks in Codex Desktop while keeping the original composer.

- Automatic Jev, suggestion-only and local-rules modes.
- Local settings, Windows-encrypted keys and an explicit connection check.
- Optional project summaries shared across conversations and multiple folders, with preview, edit and disable controls.
- Compact, resizable window with expanded view, tray access and saved dimensions.
- Dashboard separating recommendations, request configuration, upstream completion and final-message attribution.
- Tool continuations reuse the turn selection; Jev abstention or failure preserves incoming configuration.
- Windows x64 ZIP with bundled runtime, installation, updates, disable, uninstall and rollback.
- A Chinese-language management window for installation, settings, restart and update, without a terminal workflow.

Installation starts in rules mode. Configure your OpenCode Zen key and consent to task sharing before enabling automatic mode. Verify your download against `SHA256SUMS.txt`.
