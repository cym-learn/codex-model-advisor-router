# Codex Model Advisor Router

让 Codex Desktop 按任务自动选择 GPT 模型和推理强度的 Windows 工具。继续使用原来的 Codex 输入框，在小窗或本地网页查看选型和实际执行状态。

**Jev 负责选型，GPT 负责回答和执行。** 本项目是独立社区工具，与 OpenAI、TypeSafe 或 OpenCode 无官方隶属关系。

[English](README.en.md) · [安装与恢复](docs/INSTALL.md) · [隐私说明](PRIVACY.md) · [更新说明](docs/RELEASE.md)

## 能做什么

- 自动选择模型与推理强度；也可使用固定规则或只查看 Jev 建议。
- 同一轮任务的工具续跑沿用选型，新追问重新判断。
- 项目背景摘要在同项目对话间共享；多个文件夹可共用一份摘要。
- 可缩放的小窗、托盘和本地状态页，展示所属对话、模型、强度和运行状态。
- 本地管理密钥、模式、更新和恢复。Jev 放弃、超时或返回无效建议时保留传入配置。

```text
当前任务 + 必要上下文 + 可选项目摘要
                  ↓
              Jev 选型
                  ↓
          检查候选和用户配置
                  ↓
         GPT 回答、调用工具并完成
                  ↓
          小窗 / 本地状态网页
```

## 快速开始

需要 Windows x64、已安装并登录的 Codex Desktop，以及用于 Jev 的个人 [OpenCode Zen](https://opencode.ai/docs/en/zen/) 密钥。GPT 使用 Codex 现有登录；Jev 服务权限和条款另计。

1. 从本仓库 **Releases** 下载 Windows ZIP 和 `SHA256SUMS.txt`，校验后解压，双击 `Model-Advisor.vbs`（或 `Install.cmd`），在窗口里点击“安装并启动”。安装包自带 Node.js，无需另装 Python 或 Node.js。
2. 打开小窗里的“设置”，或访问 [本地设置页](http://127.0.0.1:18765/settings)。安装默认固定规则。
3. 点击“打开本机密钥窗口”，在弹出的 Windows 密码框粘贴自己的 OpenCode Zen API key 并保存。网页不会显示密钥明文；也可运行 `Configure-Jev.cmd` 在本机输入。
4. 需要时填写项目摘要。阅读发送范围，选择“Jev 自动选择”、勾选同意并点击“应用模式”。
5. 可主动点击“检查一次连接”。随后确认 Codex 对话接入本地控制器，输入配置与设置页显示的基准一致，再正常提问。

连接检查可能产生一次 Jev 请求，不会后台反复执行。支持的模型和强度以本机 Codex 模型目录为准。

## 项目摘要

在设置页“项目背景”中填写实际项目目录，**每行一个完整路径**。多个文件夹共用同一份摘要，统一修改、关闭和删除登记。

```text
C:\Projects\shop-frontend
D:\Projects\shop-backend
```

摘要可写技术栈、任务范围、文件布局和检查方式，最多 2,000 字符。预览原文后勾选授权，点击“保存并启用摘要”。工具不会自动扫描项目文件。

摘要按对话工作目录匹配，包含子目录；嵌套目录采用最具体的一项，逐对话配置优先。无法确认项目归属时不附加项目摘要。修改从下一轮生效；关闭摘要停止后续附加，不会删除已经发送的历史信息。

## 模式与状态

| 模式 | 行为 |
| --- | --- |
| Jev 自动选择 | 对符合条件的请求应用 Jev 选出的模型和强度 |
| Jev 只建议 | 展示建议，不应用 Jev 建议 |
| 固定规则 | 使用本地规则，不请求 Jev |

手动指定配置等受保护请求会保留原选择。Jev 不可用或无法给出合法建议时，也保留传入配置，不暗中用规则代选。

**Codex 输入框的模型标签可能保持不变。** 查看 [完整状态页](http://127.0.0.1:18765/) 中的推荐、请求配置、服务端完成配置和最终消息归属，区分“建议使用”与“实际完成”。旧对话可能仍连接旧 provider，可新建对话并检查归属。

![精简小窗，模拟数据](docs/assets/widget-compact.png)

小窗可以拖动、缩放和展开；关闭只隐藏窗口，后台路由继续工作。通过托盘、设置页或快捷方式重新打开。“退出小窗”也不等于停止路由；停用方法见安装与恢复说明。展示图使用模拟数据。

## 升级、停用和隐私

升级前等待任务结束，保留旧版备份。重新打开 `Model-Advisor.vbs`，即可打开设置、显示小窗、重启或更新。卸载、命令行管理与回退详见 [安装与恢复](docs/INSTALL.md)。卸载只恢复本工具管理的配置，不覆盖其他 Codex 设置。

Jev 接收当前任务文字、必要的最近上下文，以及你明确启用的匹配摘要。密钥使用 Windows 当前用户的 DPAPI 加密；项目摘要保存在本地 JSON，未加密。详见 [PRIVACY.md](PRIVACY.md)。

## 开发

Node.js 24，无 npm 生产依赖。运行 `npm test` 执行离线产品检查，不需要模型密钥。Windows 窗口检查需在交互式 Windows 会话运行。

| 目录 | 内容 |
| --- | --- |
| `src/` | 路由、Jev 接口、项目摘要和本地网页 |
| `scripts/` | 安装、管理、窗口和打包 |
| `skills/` | Codex 管理 skill |
| `test/` | 离线产品检查 |
| `docs/` | 使用说明和模拟展示 |

从源码构建见 [构建说明](docs/BUILD.md)。通过 GitHub 源码和 Windows ZIP 分发，不发布 npm 包。
